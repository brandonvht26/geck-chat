# Sesión de Trabajo - Geck Chat
**Fecha:** 31 de Mayo, 2026

## Cambios Realizados

1. **Gestión de Archivos y Audios (Compartir)**
   - Se resolvió el error de `ExpoSharing` en Android limitando el guardado a la subcarpeta `DocumentPicker` dentro de `FileSystem.cacheDirectory`, ya que Expo Go restringe compartir archivos directamente desde la raíz del caché.
   - Se arregló la generación de nombres para audios y archivos sin extensión al compartir. Los audios enviados en chats y grupos ahora se guardan temporalmente con la extensión `.m4a` y un nombre generado a partir de su ID para evitar que `expo-sharing` los rechace como carpetas o formatos inválidos.

2. **Sockets y Usuarios en Línea**
   - Se corrigió un bug en la refactorización de `socket.service.ts` donde `SocketService.emit` estaba envuelto en un `if (socket?.connected)`. Esto silenció las emisiones de socket (como `get_online_users`) que ocurren durante los milisegundos en que el socket se está inicializando, ya que Socket.io buferiza estos eventos automáticamente.
   - Se reintrodujo la petición `SocketService.emit('get_online_users')` en `SocketContext.tsx` al conectarse.

3. **Optimizaciones de UI en el Chat (Workspaces y Chats Privados)**
   - Se hizo el componente `MessageInfoModal` a prueba de fallos. Anteriormente, si los usuarios dentro de `participants` llegaban como un array de strings (IDs crudos) en lugar de objetos poblados, la función de renderizado (`renderUserRow`) retornaba `null` silenciosamente y ocultaba quién había leído el mensaje. Ahora siempre dibuja al usuario mostrando al menos su ID si falta la información del perfil.
   - Se optimizó la experiencia de envío de texto (`handleSendMessage` y `sendMessageLocal`). Ahora, al enviar un mensaje, el input se limpia instantáneamente (sin tener que esperar la respuesta de la base de datos) y se agregó un estado de bloqueo (`isSending`) para prevenir envíos duplicados accidentalmente. En caso de error, el input restaura el texto para que el usuario no lo pierda.

4. **Verificaciones Retiradas**
   - Se retiró la instrucción de verificar la actualización de fotos de avatar y wallpaper como se solicitó.
